# 导航控制器 ↔ 底盘 VCU CAN 通信协议 V0.1（草案）

适用：大蒜播种车。导航控制器为 X-MAV AP-H743v3 飞控（ArduPilot Rover 4.7.1 + Lua 脚本 `vcu_can.lua`），底盘为 VCU。
本协议只规定**运动控制**。播种作业指令先预留，本期不实现。

> 如果 VCU 已有自己的协议，请提供 DBC 或协议文档，由导航侧脚本适配，本草案作废。

## 1. 物理层

| 项目 | 约定 |
|---|---|
| 接口 | 飞控的 **CAN2** 接口。针脚顺序以飞控底面丝印或官方接线图为准 |
| 接线 | 只接 CAN_H、CAN_L、GND。**飞控 CAN 口上的 5V 脚不要接到 VCU** |
| 终端电阻 | 总线两端各 120Ω。VCU 端和飞控端要分别确认是否已内置 |
| 线缆 | 双绞屏蔽线，屏蔽层单端接地 |
| 波特率 | **500 kbit/s**（可改为 250k，两端保持一致；飞控参数 `CAN_P2_BITRATE`） |
| 帧格式 | CAN 2.0A 标准帧（11 位 ID），DLC 固定为 8 |
| 字节序 | **小端（Intel）**：多字节数据低字节在前 |
| 校验 | 每帧 Byte7 = Byte0 XOR Byte1 XOR … XOR Byte6 |

## 2. 坐标与符号

- 线速度 v：沿车头方向，**前进为正，倒车为负**，单位 m/s。
- 角速度 ω：绕竖直轴，**俯视逆时针（左转）为正**，单位 rad/s（与 ROS REP-103 一致）。
- 前轮转角 δ：**左转为正**，单位 deg。

## 3. 报文列表

| ID | 名称 | 方向 | 周期 | 超时判定 |
|---|---|---|---|---|
| 0x101 | 运动控制指令 | 导航 → VCU | 20 ms（50 Hz） | VCU 连续 200 ms 未收到，判定为丢失 |
| 0x102 | 作业控制指令（预留） | 导航 → VCU | 100 ms | 本期不发 |
| 0x201 | 运动反馈 | VCU → 导航 | 20 ms（50 Hz） | 导航侧 200 ms 未收到，判定为丢失 |
| 0x202 | 状态反馈 | VCU → 导航 | 100 ms（10 Hz） | 导航侧 500 ms 未收到，判定为丢失 |

### 3.1 0x101 运动控制指令（导航 → VCU）

| 字节 | 信号 | 类型 | 分辨率 / 说明 |
|---|---|---|---|
| 0–1 | 目标线速度 v_cmd | int16 | 0.001 m/s，范围 ±32.767 |
| 2–3 | 目标角速度 ω_cmd | int16 | 0.001 rad/s，逆时针为正 |
| 4 | 控制标志 | bit | bit0 **自动使能**：1=导航正在控车；bit1 **急停请求**：1=请求急停；bit2 **倒车**：1=v_cmd<0；bit3–7 保留为 0 |
| 5 | 保留 | uint8 | 0 |
| 6 | 滚动计数 | uint8 | 低 4 位 0–15 循环，高 4 位为 0 |
| 7 | 校验 | uint8 | Byte0..6 异或 |

### 3.2 0x201 运动反馈（VCU → 导航）

| 字节 | 信号 | 类型 | 分辨率 / 说明 |
|---|---|---|---|
| 0–1 | 实际线速度 v_act | int16 | 0.001 m/s（轮速计算） |
| 2–3 | 实际角速度 ω_act | int16 | 0.001 rad/s，逆时针为正（由 v 和 δ 推算即可） |
| 4–5 | 实际前轮转角 δ_act | int16 | 0.01 deg，左转为正 |
| 6 | 滚动计数 | uint8 | 低 4 位循环 |
| 7 | 校验 | uint8 | 异或 |

### 3.3 0x202 状态反馈（VCU → 导航）

| 字节 | 信号 | 类型 | 说明 |
|---|---|---|---|
| 0 | VCU 控制模式 | uint8 | 0=手动（驾驶/面板），1=遥控器，**2=自动（接受 0x101）**，其它=保留 |
| 1 | 状态标志 | bit | bit0 急停已触发（硬件急停或 VCU 急停）；bit1 有故障；bit2–7 保留 |
| 2–3 | 故障码 | uint16 | 0=无故障，其余由 VCU 定义并附故障码表 |
| 4–5 | 电池电压 | uint16 | 0.01 V |
| 6 | SOC | uint8 | 0–100 % |
| 7 | 校验 | uint8 | 异或 |

### 3.4 0x102 作业控制指令（预留）

Byte0 bit0 播种机构启停，bit1 升/降；Byte1 播种速率百分比；Byte6 计数；Byte7 校验。本期两端都不实现。

## 4. VCU 侧行为要求

1. **执行条件**：只有 VCU 模式 = 2（自动），**并且** 0x101 的自动使能 bit0 = 1 时，才执行 v_cmd / ω_cmd。其它情况一律按 v=0 处理（停车），转角保持当前值。
2. **通信超时**：连续 200 ms 没有收到有效 0x101（包括校验错误、计数器不变），按 VCU 最大减速度停车，并置故障位。0x101 恢复后，需要重新满足第 1 条才能继续执行。
3. **急停**：收到 bit1 = 1 立即急停。
4. **ω → 前轮转角**：由 VCU 换算，公式 δ = atan(ω·L / v)，L 为轴距。
   - |v| < 0.05 m/s 时 ω 无意义，保持当前转角，不回正；
   - δ 超过机械极限时限幅，并在 0x201 中如实反馈 δ_act。
5. **速度闭环**：v_cmd 由 VCU 做速度闭环，建议自带加减速度限制。导航侧已限制加速度 ≤ 0.5 m/s²。
6. **人工接管**：遥控器或面板切到手动时，立即放弃 0x101 控制权，并在 0x202 中上报模式 ≠ 2。
7. **倒车**：默认不使用（导航参数 `VCU_REV=0`）。

## 5. 导航侧行为（已在 `vcu_can.lua` 实现）

- ArduPilot 处于 AUTO、GUIDED、RTL、SMART_RTL、LOITER 模式且已解锁时，下发导航计算的期望 v/ω，并置自动使能位。其它情况下发 v=0、ω=0，自动使能位清零。
- 0x201 超过 200 ms 或 0x202 超过 500 ms 未收到、VCU 不在自动模式、急停、有故障，任一情况下：未解锁时**禁止解锁**（解锁前检查）；行驶中则切到 HOLD（停车保持），并在地面站报警。
- 下发值限幅：|v| ≤ `VCU_V_MAX`（默认 1.5 m/s），|ω| ≤ `VCU_W_MAX`（默认 1.0 rad/s）。
- 调试参数 `VCU_FB_TMO=0` 表示不检查 VCU 反馈，仅供台架调试。
- RTK 检查：定位未达到 `VCU_RTK_REQ` 的要求（默认只接受固定解）时禁止解锁；行驶中掉解超过 `VCU_RTK_TMO`（默认 3 s）则切 HOLD。

## 6. 示例

前进 0.8 m/s、左转 0.1 rad/s、自动使能、计数 3：

```
ID 0x101  DLC 8   20 03  64 00  01  00  03  45
v = 0x0320 = 800 → 0.800 m/s；ω = 0x0064 = 100 → 0.100 rad/s；校验 0x20^0x03^0x64^0x00^0x01^0x00^0x03 = 0x45
```

## 7. 联调检查表

- [ ] VCU 在手动模式时导航侧无法解锁（地面站提示 "VCU: not in auto"）；行驶中 VCU 切手动时导航侧切 HOLD
- [ ] 拔掉 CAN 线：VCU 在 200 ms 内停车；导航侧切 HOLD
- [ ] 0x101 ω 为正时车辆向左转；0x201 反馈的符号一致
- [ ] 急停（VCU 端、导航端）双向验证
